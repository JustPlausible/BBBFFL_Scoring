# BBBFFL_Scoring
Automated scoring system from AFL Players into Big Bad Bustling Fantasy Football League using Google Apps Script and Google Sheets

It currently includes options to pull in stats from https://www.api-football.com/ via AFL_Stats

BBBFFL Weekly Teams provides coaches weekly naming via Google Forms

BBBFFL Results combines the two, along with fixtures for the season, to automatically track, calculate and finalise results based on BBBFFL rules.
