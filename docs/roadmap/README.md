# BBBFFL engineering roadmaps

`docs/plans/` contains authoritative product/domain intent, confirmed league decisions, prototype briefs, and historical evidence. `docs/roadmap/` translates that evidence into implementation sequencing and engineering planning.

Roadmaps are living plans rather than league rules. When they differ, the season model and confirmed decisions in `docs/plans/` remain authoritative.
